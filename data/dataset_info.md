# Dataset Information

This project uses the **AI4I 2020 Predictive Maintenance Dataset** for synthetic predictive maintenance tasks.

- **Source:** Kaggle
- **Original Dataset Link:** [Kaggle - AI4I 2020 Predictive Maintenance Dataset](https://www.kaggle.com/datasets/stephanmatzka/predictive-maintenance-dataset-ai4i-2020)

### Instructions:
To run the project locally with the raw dataset:
1. Download `ai4i2020.csv` from the link above.
2. Place the file inside this `data/` directory.
